# Django Calculator

A simple calculator built with Django. It supports addition, subtraction,
multiplication, and division using decimal arithmetic.

## Run locally

```powershell
py -m venv .venv
.\.venv\Scripts\Activate.ps1
py -m pip install -r requirements.txt
py manage.py runserver
```

Open <http://127.0.0.1:8000/> in your browser.

## Run tests

```powershell
py manage.py test
```
